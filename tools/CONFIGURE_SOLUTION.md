# torchvisionlib Build Solution - Using configure Script

## Overview

Instead of modifying `src/Makevars` in the build script, we use R's standard **configure script** mechanism. The `configure` script runs automatically during `R CMD INSTALL` and generates `src/Makevars` with the correct library paths.

## Files to Add to Your Package

### 1. `configure` (in package root)
```
torchvisionlib/
├── configure          ← Add this (Unix/Linux/macOS)
├── configure.win      ← Add this (Windows)
├── src/
│   └── Makevars       ← Keep minimal defaults (gets overwritten)
└── ...
```

**Key point**: The `configure` script is automatically executed by `R CMD INSTALL` before compilation. It:
1. Finds the torch library path using R
2. Generates `src/Makevars` with the correct absolute paths
3. Works on Linux, macOS, and Windows (via `configure.win`)

### 2. How It Works

```
R CMD INSTALL
      │
      ▼
  configure script runs
      │
      ├── Finds torch: Rscript -e "cat(system.file('lib', package = 'torch'))"
      │
      └── Generates src/Makevars with:
          TORCH_LIB = /path/to/torch/lib
          PKG_LIBS = -L../inst/libs -L${TORCH_LIB} ...
      │
      ▼
  Compilation uses generated Makevars
      │
      ▼
  Package installed
```

## The configure Script

```bash
#!/bin/bash
# configure
set -e
echo "Configuring torchvisionlib..."

TORCH_LIB=$(Rscript --vanilla -e "cat(system.file('lib', package = 'torch'))" 2>/dev/null || echo "")
if [ -z "$TORCH_LIB" ] || [ ! -d "$TORCH_LIB" ]; then
    echo "ERROR: torch package not found"
    exit 1
fi

TORCH_INC=$(Rscript --vanilla -e "cat(system.file('include', package = 'torch'))" 2>/dev/null || echo "")
[ -z "$TORCH_INC" ] && TORCH_INC="${TORCH_LIB}/../include"

UNAME=$(uname)
cat > src/Makevars << EOF
# Auto-generated by configure
CXX_STD = CXX17
TORCH_LIB = ${TORCH_LIB}
TORCH_INC = ${TORCH_INC}
PKG_CPPFLAGS = -I../inst/include -I\$(TORCH_INC)
EOF

if [ "$UNAME" = "Darwin" ]; then
    cat >> src/Makevars << 'EOF'
PKG_LIBS = -L../inst/libs -L$(TORCH_LIB) -ltorchvisionlib -ltorchvision -ltorch -lc10 -Wl,-rpath,@loader_path/../inst/libs -Wl,-rpath,$(TORCH_LIB)
clean: ; rm -f *.o *.so
EOF
else
    cat >> src/Makevars << 'EOF'
PKG_LIBS = -L../inst/libs -L$(TORCH_LIB) -ltorchvisionlib -ltorchvision -ltorch -lc10 -Wl,-rpath,'$$ORIGIN/../inst/libs' -Wl,-rpath,'$(TORCH_LIB)'
clean: ; rm -f *.o *.so
EOF
fi
echo "Configuration complete."
```

## Updated Build Script

Your `tools/build_and_install.sh` should:

1. **Build native libraries** (CMake)
2. **Install to inst/libs/**
3. **Patch RPATH**
4. **Generate R documentation** (Rcpp, roxygen)
5. **Run R CMD INSTALL** (configure runs automatically)

**Do NOT generate Makevars in the build script** - let configure handle it.

## Installation Flow

```bash
# Build native libraries
./tools/build_and_install.sh

# The script runs:
# 1. CMake to build libtorchvision.so and libtorchvisionlib.so
# 2. Install libraries to inst/libs/
# 3. R CMD INSTALL (which runs configure automatically)
```

## Summary of Files

| File | Location | Purpose |
|------|----------|---------|
| `configure` | Package root | Generates Makevars on Unix/Linux/macOS |
| `configure.win` | Package root | Generates Makevars.win on Windows |
| `src/Makevars` | src/ | Minimal defaults (overwritten by configure) |
| `src/Makevars.win` | src/ | Minimal defaults for Windows |
| `tools/build_and_install.sh` | tools/ | Builds native libs, runs R CMD INSTALL |

## Benefits

1. **Standard R approach** - configure is the canonical way to handle external dependencies
2. **No manual Makevars editing** - paths are resolved at install time
3. **Portable** - works on different machines with different torch locations
4. **CRAN-compatible** - follows R package best practices
